# RevealLine music archive 02

[Listen to Archive 02](https://mekhovov.github.io/revealline-soundtracks-02/)

This is RevealLine's second immutable, hash-addressed public soundtrack archive. It starts with the exact creator-published `runner2088` MP3 and is intentionally separate from the nearly full [Archive 01](https://mekhovov.github.io/revealline-soundtracks-01/).

Publication makes a recording available for audition and online playback. It does not approve musical quality, grant Content ID clearance, enable Recording mode, or admit a recording into the game's standard playlists.

The bounded Archive 01 directory will list this archive after RevealLine's multi-archive client is publicly released. Existing Archive 01 URLs and identities remain unchanged.

See [UPLOAD_GUIDE.md](UPLOAD_GUIDE.md) for the evidence and PR process. The
checked-in `intake/add-music.mjs` command accepts one MP3 or a folder and
automates hashing, catalogue generation, verification, commit and optional PR
creation after explicit rights confirmation.
